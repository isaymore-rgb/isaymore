📡 傳送 GPS 至離線 RC-FINDER 地面站

請先在有網路時安裝 PWA 並確認離線快取完成。之後即使 GitHub 網站連不上，也可從主畫面開啟；傳送 GPS 前須連接 RC-FINDER Wi-Fi。按按鈕後會重新取得一次 GPS，然後跳轉到 http://192.168.4.1/gps/update；不是 MQTT，也不要求 ESP32 上網。

📲 安裝離線 GPS 網頁（PWA）

正在檢查離線快取…

Android：在 Chrome 選單點「安裝應用程式」或「加入主畫面」。iPhone：請使用 Safari 的「分享」→「加入主畫面」。請在 4G／5G 可正常開啟本網站時先安裝。

離線使用：安裝完成後，連接 RC-FINDER Wi-Fi，再從主畫面的 RC-FINDER GPS 圖示啟動，不要從「登入 RC-FINDER」的 Wi-Fi 登入視窗開啟。

RC-FINDER HTTP 地面站

離線 PWA 仍使用 HTTPS 安全來源，取得 GPS 後，採用整頁導覽開啟本地 HTTP 接收網址。這不屬於跨來源 fetch，所以不必設定 CORS；手機實際能否連上 192.168.4.1，仍取決於 RC-FINDER Wi-Fi／行動數據路由及瀏覽器設定。

GPS 只有在你按「傳送到 RC-FINDER」時才透過 HTTP 網址送至地面站。網址查詢參數及瀏覽器歷史紀錄可能包含 GPS 座標。GitHub Pages 不需要 MQTT。
