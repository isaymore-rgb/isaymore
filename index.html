必須先授權瀏覽器使用定位。按下「啟動 GPS」後，網頁在前景時可嘗試持續更新；鎖屏或切到背景可能暫停。

RC-FINDER HTTP 地面站

新增一鍵跳轉功能：HTTPS 頁面取得 GPS 後，使用瀏覽器頂層導覽開啟本地 HTTP 接收網址。這不屬於跨來源 fetch，所以不必設定 CORS；手機實際能否連上 192.168.4.1，仍取決於 RC-FINDER Wi-Fi／行動數據路由及瀏覽器設定。

GPS 只有在你按「傳送到 RC-FINDER」時才透過 HTTP 網址送至地面站。網址查詢參數及瀏覽器歷史紀錄可能包含 GPS 座標。GitHub Pages 不需要 MQTT。
